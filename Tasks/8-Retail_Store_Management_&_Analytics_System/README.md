# Retail Store Management and Analytics System

A simple Python project for managing retail products and sales data.

## Features

- Product management using classes and inheritance
- CSV file handling
- Sales data cleaning and analysis with Pandas
- Product, city, category, and payment reports

## Setup

Install the required packages:

```bash
pip install -r requirements.txt
```

## Run

```bash
python main.py
```

The program creates data files in `data/` and analysis reports in `output/`.

## Generated Reports

- `cleaned_sales.csv`
- `product_report.csv`
- `city_sales_report.csv`
- `category_report.csv`
- `sales_summary.txt`
