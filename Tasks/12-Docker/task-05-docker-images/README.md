# Task 05: Pull and List Docker Images

## Objective
Pull at least three images from Docker Hub and list the locally available images.

## Images

- `ubuntu:latest` — Ubuntu Linux environment
- `python:3.14-slim` — Python runtime
- `nginx:alpine` — Nginx web server

## Commands

```bash
docker pull ubuntu:latest
docker pull python:3.14-slim
docker pull nginx:alpine
docker images
```
