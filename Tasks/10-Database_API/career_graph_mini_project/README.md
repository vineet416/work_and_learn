# CareerGraph — Job Recommendation & Skill Gap Analysis

## 1. Problem Statement

Job seekers often struggle to identify suitable jobs and understand
which skills they need to learn for a target role.

CareerGraph uses a Neo4j knowledge graph to connect candidates,
skills, jobs, companies, courses, and projects.

The application can:
- Find jobs matching a candidate's skills.
- Identify missing skills for a target job.
- Recommend courses that teach missing skills.
- Find projects that build missing skills.
- Discover candidates with similar skills.
- Explore connections between candidates, jobs, and companies.

All sample data is illustrative and generated by the application.
It does not represent live job vacancies.

## 2. Technology Stack

- Python 3.10+
- Neo4j
- Cypher
- Neo4j Python Driver
- python-dotenv
- Git and GitHub

## 3. Graph Model

### Node Types

1. Candidate
2. Skill
3. Job
4. Company
5. Course
6. Project

### Relationship Types

1. HAS_SKILL: Candidate -> Skill
2. REQUIRES_SKILL: Job -> Skill
3. OFFERS: Company -> Job
4. TEACHES: Course -> Skill
5. BUILDS_SKILL: Project -> Skill
6. INTERESTED_IN: Candidate -> Job
7. COMPLETED: Candidate -> Course

## 6. File Responsibilities

- main.py: Runs the complete application.
- database.py: Manages the Neo4j connection and query execution.
- data.py: Contains the sample dataset.
- graph_setup.py: Creates constraints, nodes, relationships,
  and verifies the graph.
- crud.py: Implements candidate CRUD operations.
- queries.py: Contains 12 parameterized Cypher queries.
- .env: Stores private database credentials.

## 7. Setup

### Prerequisites

- Python 3.10 or newer
- A running Neo4j database
- Git

### Clone the repository

git clone https://github.com/YOUR_USERNAME/careergraph.git
cd careergraph

### Create a virtual environment

Windows PowerShell:

python -m venv .venv
.venv\Scripts\Activate.ps1

macOS/Linux:

python3 -m venv .venv
source .venv/bin/activate

### Install dependencies

python -m pip install -r requirements.txt

### Configure the database

Copy .env.example to .env and add your Neo4j connection details.

Windows PowerShell:

Copy-Item .env.example .env

macOS/Linux:

cp .env.example .env

Edit .env with your actual credentials.

Never commit .env to GitHub.

### Run the application

python main.py

The program connects to Neo4j, creates constraints, seeds the
graph, verifies counts, demonstrates CRUD operations, and executes
12 graph queries.

## 8. CRUD Operations

- Create: create_candidate()
- Read: read_candidate()
- Update: update_candidate()
- Delete: delete_candidate()

The demonstration uses a temporary candidate with ID C_DEMO.

## 9. Cypher Queries

The application demonstrates:

1. Candidate skills.
2. Jobs matching existing skills.
3. Missing skills for a job.
4. Courses for missing skills.
5. Jobs offered by a company.
6. Job match percentages.
7. Candidates matching a job.
8. Multi-hop candidate-skill-job-company traversal.
9. Projects for missing skills.
10. Most demanded skills.
11. Candidates with shared skills.
12. Candidate learning history.

Runtime values are passed as Cypher parameters.

## 10. Multi-Hop Traversal

Candidate -> Skill <- Job <- Company

This path identifies jobs requiring skills a candidate already
possesses and the companies offering those jobs.

## 11. Security

- Credentials are loaded from .env.
- .env is excluded from version control.
- .env.example contains placeholders only.
- Cypher values use parameters rather than string concatenation.

## 12. Limitations

- The dataset is generated sample data.
- Match percentages are based on required skills only.
- The application does not connect to live recruitment services.
- Recommendations depend on the relationships in the graph.

## 13. Learning Outcomes

This project demonstrates graph modeling, Python-to-Neo4j
integration, CRUD operations, parameterized Cypher, multi-hop
traversal, environment configuration, and Git workflows.
